## Hardware Components of the polyUAnalog System

- **Voice Board**: This is the core component of the project. A voice board is, by itself, an analog monophonic synthesizer. In short, the sound is generated by the AS3397 chip, controlled by an RP2040/RP2530 (Raspberry Pi Pico) microcontroller.

- **Conductor Board**: All voice boards are connected to the conductor board. It receives commands from external sources in MIDI-compatible format and distributes them to the voice boards via the I²C bus.

- **Controller Board**: These are the interface panels of the synthesizer. They typically include potentiometers, encoders, LEDs, and screens used to program and control the synthesizer. The corresponding data is sent to the conductor board via the I²C bus.

- **Power Board**: The synthesizer requires three power rails to operate (+12V, +5V, -5V). We provide a simple design using a USB Type-C power block with Power Delivery support to supply a regulated +12V rail. The +5V and -5V rails are then generated using buck converters.
